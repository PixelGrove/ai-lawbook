## 한국어

"AI 법전", "AI Lawbook" 이라는 이름과 저울 로고(`assets/logo.svg`, 플러그인 아이콘 `plugins/*/.claude-plugin/icon.png`)는 이 저장소
(<https://github.com/PixelGrove/ai-lawbook>)가 배포하는 공식판을 가리킵니다.

코드 라이선스([LICENSE](LICENSE), MIT + Commons Clause)는 코드를 쓰고 고치고 나누는 권리를 줄 뿐,
이 이름과 로고를 쓸 권리는 주지 않습니다.

### 허락 없이 해도 되는 것

- 글, 리뷰, 강의, 영상, 카드뉴스에서 이 프로젝트 이름을 밝혀 소개하기
- 고치지 않은 사본을 원래 이름과 로고 그대로 다시 나누기
- "AI 법전을 바탕으로 함", "AI Lawbook 호환" 처럼 사실대로 관계를 밝히기

### 하면 안 되는 것

- 고친 판(포크)이나 파생물을 같은 이름·로고, 또는 헷갈릴 만큼 비슷한 이름·로고로 배포하기
- 공식판, 공식 제휴, 공식 보증인 것처럼 보이게 하기
- 이름이나 로고를 넣은 상품·유료 서비스 만들기

포크를 배포할 때는 다른 이름을 쓰고, README 에 원본 주소
(<https://github.com/PixelGrove/ai-lawbook>)와 원래 저작권·라이선스 고지를 남겨 주세요.

### 공식 배포처

공식판은 이 GitHub 저장소와, 이 저장소를 가리키는 Claude Code 마켓플레이스
(`/plugin marketplace add PixelGrove/ai-lawbook`)에서만 배포됩니다. 다른 곳에서 "공식판"이라며
파는 사본은 이 프로젝트와 관계가 없습니다.

이름·로고 사용 문의는 이 저장소의 GitHub 이슈로 남겨 주세요.

releases from this repository (<https://github.com/PixelGrove/ai-lawbook>).

The code license ([LICENSE](LICENSE), MIT with the Commons Clause) lets you use, change, and share the
code. It does not give you the right to use these names or the logo.

### You may, without asking

- Name this project in articles, reviews, courses, videos, and social posts
- Redistribute unmodified copies under the original name and logo
- State the relationship truthfully, such as "based on AI Lawbook" or "compatible with AI Lawbook"

### You may not

- Ship a modified version (fork) or derivative under the same name or logo, or under a confusingly
  similar one
- Make anything look like an official release, partnership, or endorsement
- Sell goods or paid services that carry the name or logo

If you ship a fork, give it a different name and keep a link to the original repository
(<https://github.com/PixelGrove/ai-lawbook>) along with the original copyright and license notices.

### Official distribution

Official releases come only from this GitHub repository and from the Claude Code marketplace that
points at it (`/plugin marketplace add PixelGrove/ai-lawbook`). A copy sold elsewhere as "official"
has nothing to do with this project.

For questions about the name or logo, open a GitHub issue in this repository.
